# Crypto Flash Software

Desktop application for generating fake cryptocurrency balances and transactions across multiple blockchain networks.

## Features

- **Multi-Network Support**: Generate fake balances and transactions on TRC-20 (Tron), BEP-20 (BNB Smart Chain), and Solana networks
- **Send Tab**: Create fake transfers with network selection, amount input, destination address, and optional memo
- **Receive Tab**: Display wallet addresses, QR codes, fake balance info, and wallet compatibility status
- **History Tab**: Transaction history with direction filtering (All/IN/OUT), totals, and hash copying
- **Real-time Processing**: Live transaction stage tracking (resolving, signing, broadcasting, confirmation) with progress indicators
- **Network Telemetry**: Live latency, block height, and connection status for each network
- **Toast Notifications**: Confirmation alerts for completed transactions
- **Dark/Light Theme Support**
